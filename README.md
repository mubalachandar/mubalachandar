## 🚀 Featured Projects

### 🌟 SecOps AI Copilot — AI-Powered SOC Platform (Completed)
> *A production-ready platform that replaces traditional, manual SOC triage workflows with real-time, AI-driven automation.*

[![Repo](https://img.shields.io/badge/GitHub-Repository-181717?style=flat-square&logo=github)](https://github.com/mubalachandar/secops-ai-copilot)
[![Live Demo](https://img.shields.io/badge/Live-Demo-00C853?style=flat-square)](https://secops-copilot.vercel.app)

**Business Impact:** Ingests AWS CloudTrail logs to detect threats using MITRE ATT&CK-mapped rules. Automates the triage process using Gemini Pro, delivering risk-scored incidents to a real-time dashboard, effectively reducing alert latency to **under 30 seconds**.
* **Stack:** Node.js, PostgreSQL (pgvector), Gemini Pro, AWS CloudTrail, Upstash Redis, React
* **Architecture:** Event-driven, Microservices-ready
